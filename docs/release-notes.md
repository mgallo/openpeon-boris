Download the **boris ZIP asset** below and extract it. From the folder containing
the extracted `boris` directory, run:

```sh
peon packs install-local ./boris
peon packs use boris
```

Requires PeonPing configured for your editor. No repository clone or project
Python scripts needed. To replace an existing installation, add `--force` to
the first command.

The ZIP contains only the manifest, 16 Italian MP3 clips from Boris, and audio
credits. `SHA256SUMS` contains the archive checksum. Use the Boris ZIP asset
for installation; GitHub's automatic source archives include developer tools.

Contains explicit Italian language. This is an unofficial fan pack; all audio
rights remain with their respective owners. See `CREDITS.md` in the archive.

OpenPeon registry installation is not yet available.
